
## ⭐ Activity 1: Finding Your Way Around

### 🎯 Goal  
Learn how to check where you are and explore folders.

### 📝 Tasks
1. Open the Terminal.  
2. Type `pwd` and write down the output.
   /home/user
3. List all files in your current folder using `ls`.  
   Desktop    Downloads  Pictures  Public      Templates  yay
   Documents  Music      Projects  Roehampton  Videos
4. Move into your CLI assignment folder for Week 02:
   ```bash
   cd Roehampton
   cd Technology-Projects-BLOCK-1
   cd 1.1_software
   cd 02_CLI
   ```
5. Inside that folder, list all files (including hidden ones):
   ```bash
   ls -a

   01_simple_terminal.md  03_nano_editor.md  05_network_info.md
..  02_managing_files.md   04_basic_info.md   README.md

   ```
6. Go back to your home directory:
   ```bash
   cd ~
   ```
