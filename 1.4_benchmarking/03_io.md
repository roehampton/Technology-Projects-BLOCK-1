Task 3 — Storage Read/Write Speed
In this task, you'll test how quickly your storage device can write data to a file and read it back using the Linux dd command. You'll record both speeds in results/io.txt.
Step 1: Prepare the results folder
From your project's main directory, run:
mkdir -p results

The test creates a temporary file called testfile.bin containing approximately 100 MiB of data. Make sure you have enough free storage space.
Step 2: Run the write test
Run:
dd if=/dev/zero of=testfile.bin bs=100M count=1 oflag=direct

This command:
- if=/dev/zero — generates zeros as input.
- of=testfile.bin — writes the data to a file.
- bs=100M — uses a block size of 100 MiB.
- count=1 — writes one block.
- oflag=direct — requests direct I/O, bypassing the normal page cache for the file data.
At the end, you'll see output similar to:
1+0 records in
1+0 records out
104857600 bytes copied, 0.45 s, 233 MB/s

Record the write speed shown on your own terminal. The figures above are examples only.
Step 3: Run the read test
Run:
dd if=testfile.bin of=/dev/null bs=100M count=1 iflag=direct

This command reads the data from testfile.bin and discards it rather than saving another copy.

You'll see output similar to:
1+0 records in
1+0 records out
104857600 bytes copied, 0.30 s, 350 MB/s

Record the read speed shown on your own terminal.
Note: Direct I/O may not be supported by every filesystem or environment. If you receive an Invalid argument error, record the error and let me know your operating system and filesystem rather than assuming the test succeeded.

Step 4: Save your results
Open the results file:
nano results/io.txt

Enter the following template, replacing the placeholders with your actual results:
Storage Read/Write Speed Test
Test file: testfile.bin
Data size: 100 MiB

Write test:
Command: dd if=/dev/zero of=testfile.bin bs=100M count=1 oflag=direct
Write speed: [enter measured speed]
Time taken: [enter measured time]

Read test:
Command: dd if=testfile.bin of=/dev/null bs=100M count=1 iflag=direct
Read speed: [enter measured speed]
Time taken: [enter measured time]

Observations:
I used the dd command to measure storage write and read speeds. The write test measured how quickly data was saved to the storage device, while the read test measured how quickly the data was read back. The speeds may differ depending on the storage device and system conditions.



Save using Ctrl + O, press Enter, and exit using Ctrl + X.
Step 5: Verify the results
Run:
cat results/io.txt

You can also check the file size:
ls -lh testfile.bin

When you have finished, you can remove the temporary test file to free up space:
rm testfile.bin

Only remove testfile.bin if it is the temporary file created for this test and you no longer need it.
