- In one paragraph: interpretation vs compilation.

Interpretation and compilation are two ways of converting a program into a language that a computer can understand. In interpretation, the program is read and executed one line at a time, so errors can be found while the program is running. In compilation, the whole program is translated into machine code before it runs. Interpretation is usually slower, while compilation is generally faster during execution. Python commonly uses an interpreter, whereas C uses a compiler
