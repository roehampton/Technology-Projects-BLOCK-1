# Module Summary – 1.3 Instructions

##

In this module I learned how computers execute instructions and how different programming languages are used to create programs. I explored assembly language, C, C++, Python and Scratch. Through the activities I gained a better understanding of how instructions are processed by the computer and how different programming languages can perform similar tasks.

## What I Learned

### – Assembly Language Addition

I learned how to write an assembly language program to perform an addition. This helped me understand how the CPU works with instructions and registers to carry out calculations. I also learned that assembly language gives direct control over the operations performed by the processor.

### – Assembly Language Hello Program

I. Ran a simple assembly language program that displayed a message on the screen. This helped me understand how a program can communicate with the operating system to produce output. I also learned that even a simple output requires a sequence of instructions.

### – C Programming

I learned how to write and compile a C program. The program used variables and arithmetic operations to calculate a result. I also explored the disassembly of the compiled program. Learned how C instructions are translated into lower-level processor instructions.

### – C++ Programming

I explored how C++ can perform tasks to C. I learned that C++ uses features such as `cout` to display output while C commonly uses `printf`. I also compared the compiled programs and their disassembly to understand how different programming languages can produce machine instructions.

### – Python Programming

I learned about the difference between interpreted and compiled programming languages. Python is commonly described as an interpreted language although it also uses bytecode internally. This activity helped me understand that programming languages use methods to translate and execute instructions.

### – Scratch Programming

I used Scratch to perform a calculation using programming blocks. I set a variable changed its value and displayed the result. This showed me that programming logic can be represented visually of using written programming code. It also helped me understand variables, operations and output.

## Skills Developed

During this module I developed useful skills:

- Writing and running simple programs in different programming languages.

- Understanding variables, calculations and program output.

- Using assembly language to understand low-level computer instructions.

- Compiling programs. Examining their disassembly.

- Comparing programming languages and their execution methods.

- Understanding how visual programming works through Scratch.

- Using a terminal to run programs and examine their results.

## Overall Reflection

This module helped me understand that different programming languages can be used to perform tasks but they work in different ways. Assembly language helped me understand the relationship between instructions and the CPU while C and C++ introduced me to compiled programming. Python helped me understand interpreted execution and Scratch showed me how programming concepts can be represented using blocks.

Overall I have improved my understanding of programming concepts and how computers execute instructions. The practical activities helped me connect the theory with programs and their outputs. I now have an understanding of the different levels of programming from visual programming to low-level assembly instructions.
