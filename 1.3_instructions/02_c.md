
## 🧱 Checkpoint 3 — C Program (commit: `c-basic`)
**Files**: `c/main.c`

```c
#include <stdio.h>
int main() {
    int x = 5;
    int y = x + 3;
    printf("Result: %d\n", y);
    return 0;
}
```
Compile, run, and inspect:
```bash
gcc main.c -o main
./main
objdump -d main | head -n 60 > main.disasm.head.txt
```

Step 3: Inspect the machine instructions
Still inside the c folder, run:
objdump -d main | head -n 60 > main.disasm.head.txt

To view the saved instructions:
cat main.disasm.head.txt

This command:
- objdump -d main displays the executable's disassembled machine instructions.
- head -n 60 keeps the first 60 lines.
- > saves the output to main.disasm.head.txt.
Note: The exact instructions depend on your processor, compiler, and compiler settings. You may see extra instructions for setting up the function, preparing arguments, or returning from main.
