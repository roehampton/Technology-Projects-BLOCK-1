
## 🧱 Checkpoint 3 — C Program (commit: `c-basic`)
**Files**: `c/main.c`

```c
#include <stdio.h>
int main() {
    int x = 5;
    int y = x + 3;
    printf("Result: %d\n", y);
    return 0;
}
```
Compile, run, and inspect:
```bash
gcc main.c -o main
./main
objdump -d main | head -n 60 > main.disasm.head.txt
```
