# Journal 06 — Scratch Exercise

## Reflection
**Question:** How does Scratch's model relate to the same computation?

**Answer:**
Scratch uses a visual, block-based model to represent standard programming concepts:
- **Variables & Assignment:** Creating the variable `x` allocates memory for a named value, and `set x to 5` assigns an initial state (equivalent to `x = 5` in standard code).
- **Sequential Execution:** Snapping the blocks together vertically creates a sequential flow of execution, running instructions top-to-bottom.
- **State Mutation:** The `change x by 3` block modifies the stored value in place (equivalent to `x = x + 3` or `x += 3`).
- **Output:** The `say` block serves as an output mechanism to display the state of the variable (equivalent to `print(x)`).
