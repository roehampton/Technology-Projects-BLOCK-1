Interpretation translates and executes code line by line which doesn't need
compile and allows easier debugging, and have a more portable sorce code. However
it may give slower execution and errors during execution, on the other hand
Compilation translate the entire source code into machine code before execution
and this allows fast execution, and finding errors before running, and for it
to be optimized, but requires another step in compilation and platform executibles
which are not easily portable.
