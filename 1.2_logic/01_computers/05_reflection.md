# Part 5 – Final Reflection
Write **200–300 words** describing your learning experience during this lab.
Consider:
* What surprised you about computer hardware?
* What components were new to you?
* What challenges did you face?
* What did you learn about embedded systems?

During this lab, I learned more about computer hardware and how the different parts work together.
One thing that surprised me was that every component has its own job, but they all depend on each
other to make the computer work properly. Before learning about this, I knew some basic parts like 
the keyboard, mouse and monitor, but I did not understand as much about the components inside the computer.

Some components that were new to me were the motherboard, RAM, CPU and power supply. I learned that the CPU 
processes instructions, RAM stores data temporarily while programs are running, and the motherboard connects 
the different components. I also learned that the power supply provides electricity to the computer. 
Understanding the function of each part helped me see how a computer works as a complete system.

One challenge I faced was understanding the different components and remembering what each one does. Some parts
can look quite similar if you have not studied them before. I also needed to understand how to organise files
and images properly in my project folder. By going through the instructions and learning how to use Git Bash
and Nano, I became more familiar with working on my assignment.

I also learned about embedded systems through the Raspberry Pi. I found it interesting that many components can
fit onto one small board. This makes it useful for projects such as robotics, smart devices and home automation.
Overall, this lab helped me improve my understanding of computer hardware and gave me more confidence in learning practical computer skills.
