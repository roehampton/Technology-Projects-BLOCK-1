# Part 5 – Final Reflection
Write **200–300 words** describing your learning experience during this lab.
Consider:
* What surprised you about computer hardware?
* What components were new to you?
* What challenges did you face?

In this technology project I learned about different computer parts and their roles. One thing I didn't know before is the way the physical parts work together to make a computer work. I used to think the processor was the key part and the other parts weren't so important, but I realise that it's also necessary to have the RAM, storage, Motherboard and cooling system. I learned about the Raspberry Pi and its GPIO pins, which you can use to attach sensors and other electronic components. The concept of the SoC as a chip that performs multiple key roles in a computer was also new.

It was also a bit difficult to remember the names of the technical words and the function of it. To start off, I was a little bit of lost about RAM and storage. As I found out that RAM stores the information temporarily while the computer operating system is being used; on the other hand, storage stores the files and software even when the computer is powered off. It was not just about identifying the parts, as I found more time to learn about the details.

This project has given me a more practical understanding of embedded systems. I learnt that a Raspberry Pi is basically a small computer that can be used for projects such as controlling sensors, making a robot and creating a smart home. A lot of components are put on one board so that it takes up less space, costs less and uses less power. I feel like I have a better understanding of computer hardware and real life applications of embedded systems. I do still need practice but this project has helped me to learn the basics and has increased my interest in technology.
