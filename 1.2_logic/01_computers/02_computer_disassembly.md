# Part 2 – Computer Disassembly
## Before Opening the Computer
Describe the computer before opening it.

Before opening the computer, I could see the computer case, which protects the components inside. 
The case had ports for connecting devices such as a keyboard, mouse and monitor. It also had a power 
button and ventilation areas to help with airflow. The outside of the case keeps the internal components protected from dust and damage.

## Internal Layout
Open the computer case and observe the internal components.
Describe what you see.

Inside the computer, there are several important components connected to the motherboard. These include 
the CPU, RAM, storage drive, power supply and cooling fans. The motherboard allows the components to 
communicate with each other. The CPU processes instructions, while the RAM temporarily stores data for 
running programs. The cooling system helps prevent the computer from overheating.
