# Part 2 – Computer Disassembly
## Before Opening the Computer
The computer is a Raspberry Pi inside a small plastic case. It is much smaller than a normal desktop computer, about the size of a credit card. On the sides of the case there are openings for the ports: USB ports, an Ethernet port, a USB-C power port, micro-HDMI ports for connecting monitors, an audio jack and a microSD card slot. There is no power button, so the device turns on as soon as it is connected to power.

## Internal Layout
Open the computer case and observe the internal components.

After removing the top of the case, the whole circuit board became visible. All the main components are placed on one small board instead of separate parts like in a desktop PC. In the centre there is the processor (a Broadcom system-on-chip), which contains the CPU and GPU together. Next to it is the RAM chip. I could also see the USB and Ethernet controller, the GPIO pins along one edge of the board used for connecting electronics, the wireless chip for Wi-Fi and Bluetooth, and the microSD card slot underneath, which is used instead of a hard drive to store the operating system.
