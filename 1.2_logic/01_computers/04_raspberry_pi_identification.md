|-----------|----------|
| SoC | Integrates the CPU, GPU, memory controller, and other functions into a single chip.|
| GPIO |Allows the Raspberry Pi to connect and interact with external electronic devices such as LEDs, sensors, and motors. |
| USB |Connects peripherals such as keyboards, mice, storage devices, and printers. |
| HDMI |Provides video and audio output to a monitor, TV, or projector. |
| Power |Supplies electrical power required for the Raspberry Pi to operate. |
| microSD | Stores the operating system, applications, and user files.|
| Network |Enables wired internet and network connectivity through an Ethernet connection. |
| Wireless |Provides Wi‑Fi and Bluetooth connectivity for wireless networking and communication with other devices.|

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Many components are integrated into a single board in embedded computers such as the Raspberry Pi to make the system smaller, cheaper, and more efficient. By combining the CPU, RAM, storage interfaces, and other components onto one board, less space is required and fewer connections are needed. This reduces power consumption and improves reliability because there are fewer parts that can fail. Integration also makes the device easier to manufacture and maintain. Embedded computers are often used in robots, smart devices, and control systems where compact size, low cost, and dependable performance are important. This design helps achieve those goals effectively
