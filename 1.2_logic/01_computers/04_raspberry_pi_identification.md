| Component | Function |
|-----------|----------|
| SoC |System on a Chip combines important parts, such as the processor and graphics processor into one chip. |
| GPIO |Pins that connect the Raspberry Pi to external electronics, such as sensors, LEDs and buttons. |
| USB |Connects devices such as a keyboard, mouse and USB storage. |
| HDMI |Sends video and audio to a compatible monitor or television. |
| Power |Supplies electrical power to the board through its power connector. |
| microSD |Stores the operating system, programs and files. |
| Network |Allows a wired network connection through an Ethernet port, if the model has one. |
| Wireless |Provides wireless connections such as Wi-Fi and Bluetooth, if supported by the model. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Integrated computers like the Raspberry Pi have a number of elements built-in to one circuit board because of the requirement that it should be small, efficient, and inexpensive. Integrating all the circuits such as the microprocessor circuit, memory interfacing circuit, USB interfacing circuit, network interfacing circuit, and other circuits eliminates the need for external circuits and wires. This helps in keeping the circuit small and easy to assemble in a project. The integration process can also help in reducing energy consumption and making communication between various components easier. Single circuit boards are useful in applications such as robotics, home automation, education, and the Internet of Things.
