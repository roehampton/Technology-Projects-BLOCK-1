| Component | Function |
|-----------|----------|
| SoC | Contains the processor and other important computing components on a single chip.|
| GPIO | Allows the Raspberry Pi to connect and communicate with external electronic components and sensors|
| USB | Connects devices such as keyboards, mice and USB storage |
| HDMI | Sends digital video and audio to a monitor or television  |
| Power | Supplies electrical power to the Raspberry Pi through its power connector |
| microSD | Stores the operating system, programs and files |
| Network | Provides a wired network connection through Ethernet, if available on the model |
| Wireless | Provides wireless connectivity, such as Wi-Fi and Bluetooth, if supported by the model |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Embedded computers such as the Raspberry Pi integrate many components onto a single board to make them compact, affordable and energy-efficient. This design reduces the need for separate hardware and cables, saving space and making the system easier to use. Integrating the processor, memory connections, networking and other interfaces also helps components communicate efficiently. A small board can be used in many projects, including robotics, home automation, education and Internet of Things devices. It usually consumes less power than a full desktop computer. Overall, integrating components makes embedded computers practical, portable and suitable for tasks with limited space and power.
