| Component | Function |
|-----------|----------|
| SoC | Contains the processor and other important circuits that run the Raspberry Pi. |
| GPIO | Allows you to connect and control external electronic components, such as sensors and LEDs. |
| USB | Connects devices such as a keyboard, mouse or USB drive. |
| HDMI | Connects the Raspberry Pi to a monitor or TV to display video and audio. |
| Power | Supplies electrical power to the Raspberry Pi. |
| microSD | Stores the operating system, programs and files. |
| Network | Connects the Raspberry Pi to a network, usually through an Ethernet cable. |
| Wireless | Allows wireless connections using Wi-Fi and Bluetooth on supported models. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Many components are integrated into one board in embedded computers like the Raspberry Pi because it 
makes the device smaller and easier to use. Having the CPU, RAM, network connections and other components 
on one board saves space and reduces the number of separate parts needed. It can also help reduce cost and 
power consumption. Since the components are connected on the same board, they can communicate efficiently. 
This design is useful for projects such as robotics, smart home devices and small computer systems. Overall, 
integrating components makes the Raspberry Pi compact, practical and suitable for many different applications.
