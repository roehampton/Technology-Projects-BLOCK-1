# Part 4 – Raspberry Pi Hardware Identification

| **Component** | **Function** |
|---|---|
| **SoC (System on a Chip)** | The SoC contains the processor and other important parts that help the Raspberry Pi run programs and process information. |
| **GPIO** | GPIO pins allow you to connect electronic components, such as LEDs, sensors and buttons, to the Raspberry Pi. |
| **USB** | USB ports allow you to connect devices such as a keyboard, mouse and USB storage drive. |
| **HDMI** | The HDMI port connects the Raspberry Pi to a monitor or television so that it can display images and videos. |
| **Power** | The power connection supplies electricity to the Raspberry Pi so that it can operate. |
| **microSD** | The microSD card stores the operating system, programs and files needed by the Raspberry Pi. |
| **Network** | The network connection, usually an Ethernet port on supported models, allows the Raspberry Pi to connect to a wired network and the internet. |
| **Wireless** | Wireless features, such as Wi-Fi and Bluetooth on supported models, allow the Raspberry Pi to connect to networks and other devices without cables. |

## Reflection

Many components are built into one board in embedded computers like the Raspberry Pi because it makes them smaller, cheaper and easier to use. Having everything on one board saves space and reduces the number of separate parts needed. It also uses less power, which is useful for devices that run for long periods. The components can communicate with each other directly, making the system more efficient. This design is useful for projects such as robots, smart home devices and sensors. Overall, putting the components together makes the Raspberry Pi compact, affordable and suitable for many different purposes.
