| Component | Function |
|-----------|----------|
| SoC | |The SoC is the main chip of the Raspberry Pi. It contains the processor and other important components that help the computer run                 programs and perform tasks.
| GPIO | | GPIO pins allow the Raspberry Pi to connect and communicate with external electronic devices, such as LEDs, sensors, buttons, and                 motors.
| USB | | USB ports are used to connect devices such as a keyboard, mouse, USB drive, and other accessories to the Raspberry Pi.
| HDMI | | The HDMI port connects the Raspberry Pi to a monitor or television so that I can see the display and use the computer.
| Power | | The power connection supplies electricity to the Raspberry Pi so that it can switch on and operate properly.
| microSD | | The microSD card stores the operating system, software, and files. It allows the Raspberry Pi to start up and run programs.
| Network | | The network port provides a wired Ethernet connection, allowing the Raspberry Pi to connect to the internet or a local network.
|Wireless| | Wireless connectivity allows the Raspberry Pi to connect to Wi-Fi and, on supported models, Bluetooth devices without needing extra cables.

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.
ANSWER = Many components are integrated into a single board in embedded computers like the Raspberry Pi to make them smaller, cheaper, and more efficient. Having the processor, memory connections, USB ports, and other components on one board means that fewer extra parts and cables are needed. This also saves space and makes the device easier to carry and use. The integrated design helps different components communicate with each other efficiently. It also reduces power consumption and makes the Raspberry Pi useful for many projects, such as robotics, home automation, and learning programming. Overall, this design makes computing more affordable and accessible.
