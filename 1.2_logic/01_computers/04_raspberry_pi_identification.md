3. Component Identification Table
Component

Function

SoC (System on Chip)

The SoC combines the processor (CPU) and other important functions on a single chip. It executes instructions and processes data to run the operating system and applications.

GPIO (General-Purpose Input/Output)

GPIO pins allow the Raspberry Pi to connect to and control external electronic components, such as LEDs, sensors, buttons, and motors.

USB (Universal Serial Bus)

USB ports connect external devices such as keyboards, mice, flash drives, and other peripherals to the Raspberry Pi.

HDMI (High-Definition Multimedia Interface)

HDMI ports transmit digital video and audio signals to a compatible monitor or television.

Power

The power connector supplies electricity to the Raspberry Pi so that it can operate. The Raspberry Pi 4 Model B uses USB-C for power.

microSD

The microSD card stores the operating system, applications, and files. The Raspberry Pi uses it to boot and run its software.

Network (Ethernet)

The Ethernet port provides a wired network connection, allowing the Raspberry Pi to access the internet and communicate with other devices.

Wireless

Built-in Wi-Fi enables wireless network and internet connections. Bluetooth allows the Raspberry Pi to connect to compatible wireless devices.

## Reflection
 Reflection: Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Embedded computers such as the Raspberry Pi integrate many components onto a single board to reduce size, cost, and power consumption. This compact design makes them suitable for projects where space is limited. Integrating components also reduces the need for additional cables and separate hardware, making the system easier to assemble and maintain. The components can communicate efficiently because they are connected on the same board. This design is useful in robotics, home automation, education, and Internet of Things (IoT) projects. Overall, integrating components makes embedded computers affordable, portable, energy-efficient, and practical for many applications.
