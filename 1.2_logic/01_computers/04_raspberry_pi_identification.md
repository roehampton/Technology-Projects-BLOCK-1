| Component | Function |
|-----------|----------|
| SoC |Processes data and runs instructions, acting as the main processor of the Raspberry Pi. |
| GPIO |Allows the Raspberry Pi to connect and communicate with electronic components such as sensors, LEDs and motors.|
| USB |Connect external devices such as a keyboard, mouse and USB drive. |
| HDMI |Connects the Raspberry Pi to a monitor or TV to display video and audio. |
| Power |Supplies electrical power to the Raspberry Pi so it can operate. |
| microSD |Holds the microSD card, which stores the operating system, programs and files. |
| Network |Connects the Raspberry Pi to a wired network or the internet. |
| Wireless |Allows wireless connections and communication with devices such as headphones, speakers and other compatible devices. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

In embedded computers like the Raspberry Pi, many components are placed on a single board to make the device smaller, cheaper and easier to use. Instead of connecting different parts separately, everything is arranged together so that it can work properly. This design also reduces the number of wires and saves space. Another benefit is that the computer uses less electricity and is easier to carry from one place to another. Since it is small and affordable, the Raspberry Pi is commonly used by students and beginners for learning programming, building robots and working on different electronic projects.
