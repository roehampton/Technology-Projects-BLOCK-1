# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |Executes instructions and performs calculations.|Clock speed (GHz), number of cores, cache size.|
| RAM |Temporarily stores data and programs currently in use. |Capacity (GB), speed (MHz/MT/s). |
| Storage |Stores operating systems, applications, and files permanently.|Capacity (GB/TB), type (SSD or HDD). |
| Motherboard |Connects and allows communication between all computer components. |Socket type, chipset, expansion slots. |
| Power Supply |Provides electrical power to all computer components. |Wattage (W), efficiency rating (80 Plus). |
| Cooling |Prevents overheating by removing excess heat from components. |Air or liquid cooling, fan size, cooling performance. |
