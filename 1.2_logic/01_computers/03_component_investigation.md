| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |processes instructions, performs calculation, and manages data flow between components. |Model, number of cores, clock speed|
| RAM |provides volatile, high speed temporary storage for data currently being used by active programs. |Capacity (GB), speed (MHZ), and DDR type (DDR4) |
| Storage |holds non-volatile, permanent data including the operating system, applications, and user files. |Capacity (GB or TB), type (SSD or HDD) |
| Motherboard | acts as the main printed circuit board that physically connects and enables communication between all hardware |Socket type, chipset, RAM compatibility, and ex |
| Power Supply |converts alternating current(AC) from a wall outlet into regulated direct current(DC) power for internal parts. |Power output (watts), efficiency rating, and co |
| Cooling |Dissipates thermal energy produced by high heat components to maintain safe operating temperatures. |fan size, cooling capacity |
