1. Introduction
Computer hardware consists of the physical parts of a computer that can be seen and touched. Different hardware components work together to allow a computer to process information, store files, run programs, and perform tasks. This investigation examines six important computer components: the CPU, RAM, storage, motherboard, power supply, and cooling system. It explains the function and key specifications of each component.

4. Conclusion
This investigation shows that each computer hardware component has an important role. The CPU processes instructions, RAM temporarily holds active data, and storage saves files for long-term use. The motherboard connects the components, while the power supply provides electricity and the cooling system prevents overheating. The specifications of these components affect computer performance, compatibility, and reliability. Understanding their functions helps explain how a computer operates as a complete system.
