| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |Processes instructions, performs calculations, and controls computer operations. |Clock speed (GHz), number of cores, number of threads, cache size. |
| RAM |Temporarily stores data and programs currently being used by the computer. |Capacity (GB), memory type (DDR4/DDR5), speed (MHz). |
| Storage |Stores the operating system, applications, documents, and other files permanently. |Capacity (GB/TB), type (SSD/HDD), read/write speed. |
| Motherboard |	Connects all computer components and allows them to communicate with each other. | Form factor (ATX/Micro-ATX), CPU socket, RAM slots, expansion slots.|
| Power Supply |Converts AC electricity into DC power required by computer components. |Power output (watts), efficiency rating, connectors. |
| Cooling |Removes heat from internal components and prevents overheating. |Cooling type (air/liquid), fan size (mm), fan speed (RPM). |
