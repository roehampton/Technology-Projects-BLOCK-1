| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Processes instructions and performs calculations, it is the brain of the computer | Broadcom BCM2711, quad-core ARM Cortex-A72, 1.5 GHz |
| RAM | Temporary memory that stores data and programs currently in use | 1 GB LPDDR4 |
| Storage | Permanently stores the operating system, programs and files | microSD card, 32 GB |
| Motherboard | The main circuit board that connects all components and lets them communicate | Raspberry Pi 4 |
| Power Supply | Converts mains electricity into the low voltage | 5V 3A, USB-C connector |
| Cooling | Removes heat from the CPU to prevent overheating | Passive aluminium heatsink on the CPU |
