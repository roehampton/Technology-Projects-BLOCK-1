# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |To process all data and execute program instructions. |Model & Speed: Brand(Intel/AMD),series(e.g., Corei5, Ryzen7), and clock speed in GHz. |
| RAM |To hold the data temporarily which active programs need to access immediately. |Capacity & Type: Total size in gigabytes(e.g.,8GB,16GB) and generation type(e.g.,DDR4,DDR5).|
| Storage |Permanent long term memory where operating system, files, apps and games are saved. |Type & Capacity: Drive format(SSD or HDD) and maximum storage capacity(e.g, 512GB, 1TB). |
| Motherboard |It connects all internal components and lets them communicate. |Form Factor & Chipset: Board size configuration and manufacturer model series. |
| Power Supply |To convert high voltage AC electricity from wall outlet into usable DC power for internal parts. |Wattage & Efficiency: Total maximum power output in watts and its efficiency rating. |
| Cooling |TO dissipates heat generated by the CPU and other parts using fans or metal heatsinks to avoid crashing. |Cooling Type: Active air cooler fan size(e.g.,120mm) of configuration layout (Liquid AIO vs Air heatsink).  |
