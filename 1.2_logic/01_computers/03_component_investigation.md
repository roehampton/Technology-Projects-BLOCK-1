# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Processes instructions and performs calculations.|AMD Ryzen 5 7430U, 6 cores and 12 threads |
| RAM | Temporarily stores data for programs currently running. |16 GB RAM |
| Storage | Stores the operating system, applications and files. |SSD; exact capacity and type should be checked. |
| Motherboard | Connects the CPU, RAM, storage and other components. |Laptop motherboard designed for the Acer TravelLite model. || Power Supply |Provides electrical power to the computer. |Laptop AC adapter and internal rechargeable battery. |
| Cooling | Removes heat from the CPU to prevent overheating. | Cooling fan and heat pipe|
