# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Executes instructions and calculations. | Model and clock speed (GHz) |
| RAM | Temporarily holds data for active programs. | Capacity (GB) and speed (MT/s) |
| Storage | Saves files and software permanently. | Capacity (GB/TB) and SSD/HDD type |
| Motherboard | Connects components and allows them to communicate. | Model and supported CPU/RAM |
| Power Supply | Provides power to the computer. | Wattage (W) and efficiency rating |
| Cooling | Keeps components from overheating. | Cooler type and fan size (mm) |
