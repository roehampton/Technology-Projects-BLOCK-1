# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU      |Processes intructions and data |Speed (GHz) and number of cores |
| RAM      |Temporarily stores data used by the computer |Capacity (GB) |
| Storage |Stores files, programs and the operating system |Capacity and type |
| Motherboard |Connects all computer components |Form factor and compatibility |
| Power Supply |Provides electrical power to all components |Power output |
| Cooling |Keeps components from overheating |Cooling type and fan size |
