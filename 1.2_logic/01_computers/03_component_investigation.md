# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
1.2_logic/01_computers/images/Components
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |The Central Processing Unit (CPU) processes instructions and performs calculations. It acts as the computer's brain. |Manufacturer, model, number of cores, and clock speed. |
| RAM |Random Access Memory (RAM) temporarily stores data and programs currently being used by the computer. |Capacity (e.g. 8 GB or 16 GB), DDR generation, and speed. |
| Storage |Storage permanently saves the operating system, applications, and personal files. |Type (SSD or HDD), capacity (e.g. 256 GB, 512 GB or 1TB), and connection type. |
| Motherboard |The motherboard connects the CPU, RAM, storage, and other components so they can communicate. |Manufacturer, model, form factor, and supported RAM type. |
| Power Supply |The Power Supply Unit (PSU) converts electricity from the mains into power that the computer components can use. |Wattage (e.g. 500 W), efficiency rating, and model. |
| Cooling |Cooling fans or heatsinks remove heat from components and help prevent overheating. |Cooling type, fan size, and fan speed, if available. |
