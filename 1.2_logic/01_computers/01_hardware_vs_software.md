# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Hardware is the parts of a computer that we can physically touch. For example, a keyboard, mouse, screen and CPU are all hardware.
Each part has a different job. We use the keyboard to type, the mouse to click on things and the screen to see what is happening on
the computer. Without hardware, we would not have a physical device to use for our daily tasks.
## Explain Software
Write **at least 50 words** explaining what software is.
---
Software is what makes a computer do different tasks. We cannot touch software like we can touch a keyboard or a mouse because it 
consists of programs and instructions. Some examples are Windows, Google Chrome and Microsoft Word. We use these programs for different 
reasons, such as browsing websites, doing assignments and watching videos. Software is important because it tells the computer what to do when we use it.
## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together when we use a computer. For example, when I open Google Chrome and search for something, I use the mouse or keyboard 
to give commands. The software processes what I ask it to do, while the computer's hardware helps carry out the task and show the results on the screen. 
This is why both are needed. Hardware provides the physical parts, and software makes those parts useful.
