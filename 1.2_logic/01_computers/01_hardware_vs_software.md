# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Computer Hardware means to the tangible physical parts of a computer system that you can see, touch, and assemble. Actually hardware acts as the "body" of the machine and performs vital functions such as input, processing, storage and output. It acts as a platform where user can run computer software, also acts as a between the digital and physical worlds.

## Explain Software
Write **at least 50 words** explaining what software is.
---Computer software refers to the set of instructions, data or programs used to operate computers and execute specific tasks.It needs computer hardware to run. Basically we can that if hardware is the "body" of the computer system then software is its "soul". So software is the digital brain tells the hardware what to do and allows user to interact with their computer.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
--Software and Hardware interact through a continuous loop of communication where the software acts as the thinker and the hardware acts as the doer. When user use a computer, software translates user commands into electrical signals. It then passes the signals down to the physical hardware which execute the actual work and sends the results back up to the software after completion of the work. And the result is displayed on the user's screen.
