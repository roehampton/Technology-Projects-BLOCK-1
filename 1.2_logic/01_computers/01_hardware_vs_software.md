# Part 1 – Hardware vs Software

## Explain Hardware
Hardware is the physical part of a computer that you can see and touch. It includes devices such as the keyboard, mouse, monitor, CPU, printer, and hard drive. Hardware works with software to perform tasks, process data, store information, and display results to the user effectively.

## Explain Software
Software is a collection of programs, instructions, and data that tell a computer how to perform tasks. It includes operating systems, applications, and utilities. Software works with hardware to process information, run programs, manage resources, and help users complete tasks efficiently and effectively on digital devices.

## How Do Hardware and Software Interact?
Hardware and software interact by working together to perform tasks. Software provides instructions, and hardware carries them out.

For example, when you open a web browser:

The software (browser) receives your command.
The operating system sends instructions to the hardware.
The CPU processes the instructions.
The RAM stores data temporarily.
The monitor displays the webpage.

In simple terms: Software tells the hardware what to do, and hardware performs the task and produces the result. Without software, hardware cannot function effectively, and without hardware, software cannot run.
