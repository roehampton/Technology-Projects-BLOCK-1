# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware is the physical part of a computer system that you can see and touch. It includes devices such as the monitor, keyboard, mouse, printer, hard drive, motherboard, and central processing unit (CPU). Hardware works together with software, which is the set of instructions that tells the hardware what to do. Without hardware, a computer cannot function because there would be no physical components to process, store, or display information. Examples of hardware can be found in desktop computers, laptops, smartphones, and tablets. Hardware is essential for performing tasks such as typing documents, browsing the internet, playing games, and storing data. It forms the foundation of all digital technology.

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a collection of programs, instructions, and data that tell a computer how to perform specific tasks. Unlike hardware, software cannot be physically touched because it exists in a digital form. Examples of software include operating systems such as Windows, mobile apps, web browsers, word processors, and games. Software works together with hardware to make a computer functional and useful. It allows users to create documents, browse the internet, communicate with others, and perform many other activities. Without software, computer hardware would not be able to carry out any meaningful tasks because it would have no instructions to follow. Software is an essential component of all modern computing devices.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software interact by working together to perform tasks on a computer. Hardware includes the physical parts of a computer, such as the keyboard, mouse, monitor, CPU, and hard drive. Software consists of the programs and instructions that tell the hardware what to do.

When a user performs an action, such as opening an application or typing a document, the software sends instructions to the hardware. The CPU processes these instructions, memory stores the data, and output devices such as monitors display the results. For example, when you click a web browser icon, the software tells the hardware to load and display the browser on the screen.

Hardware and software depend on each other to function correctly. Without software, hardware cannot perform useful tasks, and without hardware, software has no device on which to run. Together, they enable computers to operate efficiently and carry out a wide range of activities.
