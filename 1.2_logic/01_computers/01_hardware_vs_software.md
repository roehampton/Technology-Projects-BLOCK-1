# Part 1 – Hardware vs Software


## Explain Hardware
Hardware: The physical parts of a computer or electronic system that are visible and can be touched. These include the keyboard, monitor, motherboard, processor, memory, storage drive and mouse. The function each component carries out is specific to that component. For instance, the processor performs instructions and the storage drive stores files and programs. Software requires hardware to execute the instructions and to be useful.
## Explain Software
Software consists of instructions, data and programs that instruct computer hardware on how to do things. However, software is intangible, unlike hardware. This can refer to software like operating systems, web browsers, games, word processors, or mobile apps. The resources of the computer are controlled by the system software and the application software enables user to do specific jobs. Typically software is stored on a device and transferred to memory when required.
## How Do Hardware and Software Interact?
A computer system is composed of hardware and software. Hardware executes programs of instructions(software). For instance, if a user is typing on a word processor, the keyboard senses the typing, the word processor software interprets the instruction, and the word processor monitor shows the letters that are being typed. The operating system makes this more effective in managing hardware resources and sharing them efficiently with others.
