# Part 1 – Hardware vs Software



## Hardware is the physical part of a computer system that you can actually see and touch. It includes internal components such as the CPU, RAM, motherboard, power supply and storage drives HDD or SSD, as well as external devices like the monitor, keyboard, mouse and printer. Hardware performs the real physical work: it processes electrical signals, stores data and displays results. Without hardware, software would have nothing to run on.

## 

## Software is a set of instructions, programs and data that tells the hardware what to do. Unlike hardware, it cannot be touched because it exists as code stored in memory. There are two main types: system software, such as operating systems Windows, Linux, macOS, which manage the hardware, and application software, such as web browsers, games and text editors, which help users complete specific tasks.

## How Do Hardware and Software Interact? 

## 

## Hardware and software depend on each other to make a computer work. Software gives instructions, and hardware carries them out. For example, when you press a key, the keyboard hardware sends a signal, the operating system and driver software interpret it, the CPU processes it, and the result appears on the monitor. The operating system acts as a bridge, managing hardware resources so applications can use them without controlling the components directly.
