# Part 1 – Hardware vs Software

## Explain Hardware.
Write **at least 50 words** explaining what hardware is.


Hardware can be defined as the physical part of computer which can be seen and touched by us. It helps a computer receive the data, process it and give the output as a result. For example, when I search for something on my computer, the keyboard in our computer sends the data and the monitor of device gives the result. For example: Keyboard, mouse, CPU, RAM, ROM, monitor, printer, etc.
