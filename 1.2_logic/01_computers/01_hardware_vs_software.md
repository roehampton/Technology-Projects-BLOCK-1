# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Hardware is a physical component of a computer system that we can move, replace, or touch. 
Hardware includes the GPU, CPU, RAM, and SSD that help the computer run smoothly and interact with software accordingly.
Hardware includes some input and output devices like a keyboard, mouse, monitor, loudspeaker, and more.


## Explain Software
Write **at least 50 words** explaining what software is.
---
Software is a program or system with sets of instructions to operate and communicate, and run the hardware. It can be an application, a set of code, an operating system, or data.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
---
Hardware interacts with software through a structured hierarchy that starts with the CPU, which processes information through the fetch-decode-execute cycle.
* **Fetch** - takes an instruction from RAM.
* **Decode** - decodes the code and explains what to do
* **Execute** - the ALU processes the physical operation
