## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Software and hardware work together to make a computer function.Hardware is the physical part of the computer, such as the keyboard, monitor, processor and mouse. Software provides instructions that tell the hardware what to do. For example, when we open a web browser, the software sends instructions to the processor, and the monitor displays the information. Without hardware, software cannot run, and without software, hardware cannot perform useful tasks.
