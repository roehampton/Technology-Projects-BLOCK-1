# Part 1 – Hardware vs Software

## Explain Hardware
Hardware is the physical part of the computer that we can touch and see.there are many different types of hardware , such as keyboard,mouse,monitor,CPU,motherboard and hard drive.Every parts has its own function.for example , we use a keyboard to type information,and monitor shows the information on the screen.Hardware is important because it helps a computer perform different tasks.

## Explain Software
Software is program or a set of instructon that tells a computer what to do.we cannot see or touch software like physical computer parts. There are different types of software that we use in our daily lives. For example, windows,google chrome and microsoft word and software . We use software to browse the internet , write documents, watch videos and complete different activites on a computer.

## How Do Hardware and Software Interact?
hardware and software work together to make a computer function properly. hardware is the physical Part of computer,while software provides instruction to it.for example., when i type something using a keyboard,the computer receives the information and process it through software. after processing, the result appears on the  monitor. both are important because hardware and software depend on each other to make a computer work correctly.
