# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical, tangible parts of a computer system that you can touch and see. This includes internal components like the CPU, memory, and hard drive, as well as external devices like the keyboard, mouse, and monitor

## Explain Software
Write **at least 50 words** explaining what software is.
Software is the set of digital instructions, programs, and data that tells a computer's hardware what to do and how to function. While you cannot physically touch it, software brings hardware to life, powering everything from operating systems to web browsers and mobile apps.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Software provides instructions telling physical hardware what to do. The hardware processes these digital commands using its components, turning code into real actions. Software needs hardware to run, and hardware needs software to function. Together, they constantly communicate behind the scenes to make your computer work smoothly every single day.
