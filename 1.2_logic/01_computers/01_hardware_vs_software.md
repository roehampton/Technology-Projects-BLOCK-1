# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Computer hardware is the physical parts of a computer that we can see and touch which helps a computer to perform different tasks, such as processing information, storing data, displaying images, and running programs .Examples includes the keyboard, mouse, monitor, CPU, and motherboard. Without hardware, a computer cannot function properly.

## Explain Software
Write **at least 50 words** explaining what software is.
---
Software is a set of programs and instructions that tells a computer what to do and helps us to perform tasks such as writing documents, browsing the internet, editing photos, and communicating with others easily. Unlike hardware, software cannot be touched physically. Examples include Windows, Microsoft Word, Google Chrome, and games

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software are the parts of the computer which works together to make a computer function properly. Hardware is the physical part and software gives instruction to the hardware. Just example if we type anything on the keyboard then the software process the input and displays on the monitor.
