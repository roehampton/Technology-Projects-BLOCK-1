# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

The computer hardware refers to the physical parts of the computer that can be seen and handled. The hardware includes items like the keyboard, mouse, monitor, motherboard, central processing unit (CPU), random access memory (RAM), and storage media such as the hard disk. Each individual piece plays a unique part in the functioning of the computer as a whole. For example, the keyboard helps in entering data into the computer, the monitor displays graphics, and the CPU carries out all commands. Hardware is therefore essential for any computer to function. Hardware is thus the physical makeup of a computer, whereas the software gives instructions on how to use it.
---

## Explain Software
Write **at least 50 words** explaining what software is.

Software consists of a set of programs that guide the functioning of computers and regulate how various processes are performed on the computer. Through software, people are able to make use of computers in performing their activities through a variety of applications. There are generally two major kinds of software; these include system software and application software. System software includes operating systems like Windows, Linux, and macOS, as well as device drivers that facilitate the appropriate performance of hardware. Application software includes such programs like Microsoft Word, Excel, Powerpoint, Google Chrome, Adobe Photoshop, VLC Media Player, Zoom, and WhatsApp. These help perform various activities such as studying, working in offices, browsing, editing photos, watching videos, and social interactions.
---

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software work together in ensuring the functioning of the computer. Hardware refers to the physical parts of the computer, which include the keyboard, mouse, monitor, and the central processing unit, while software refers to the programs that tell the computer what actions to take. Once a command is issued through the software, the CPU understands the instructions and the hardware takes the necessary action. For example, once text is entered through the keyboard in Microsoft Word and is processed through the software, the characters will be displayed on the monitor.
