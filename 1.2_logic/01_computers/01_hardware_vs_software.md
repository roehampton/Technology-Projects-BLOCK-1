# Part 1 – Hardware vs Software

## Explain Hardware.
Write **at least 50 words** explaining what hardware is.


Hardware can be defined as the tangible, physical part of computer which can be seen and touched by us. It helps a computer receive the data, process it and give the output as a result. For example, when I search for something on my computer, the keyboard in our computer sends the data and the monitor of device gives the result. For example: Keyboard, mouse, CPU, RAM, ROM, monitor, printer, etc.

## How Do Hardware and Software Interact?

Hardware and software are dependent upon each other for working. Hardware is the physical machine, while software is the digital instructions that tells the machine what to do. The combination of hardware and software makes a computer.
