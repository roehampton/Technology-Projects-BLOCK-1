# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Hardware is defined as the physical parts of a computer that we can see and touch. It includes devices such as the keyboard, mouse, monitor, CPU, motherboard, RAM, and hard drive. Hardware works together to process data, store information, and perform different tasks according to the instructions given by software.
## Explain Software
Write **at least 50 words** explaining what software is.
---
Software is a collection of programs and instructions that tells a computer what to do. It helps users perform different tasks, such as writing documents, browsing the internet, and playing games. Software cannot be physically touched. Examples include Windows, Microsoft Word, Google Chrome, and antivirus programs.
## How Do Hardware and Software Interact?
Hardware and software interact to make a computer work together. Hardware refers to the physical components, while software provides instructions to the hardware. For example, when you type on a keyboard, the software processes your input and displays the text on the monitor. Both are essential for a computer to function properly.
