# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
= Hardware is the physical parts of a computer that you can see and touch. Examples of hardware include the keyboard, mouse, monitor, printer and the computer itself. The CPU is also a type of hardware because it processes information and carries out instructions. Hardware is important because it allows us to use a computer to type, save files, play games and complete other tasks.

## Explain Software
Write **at least 50 words** explaining what software is.
= Software is the programs and applications that tell a computer what to do. Unlike hardware, you cannot physically touch software. Examples include Windows, Google Chrome and Microsoft Word. Software allows people to do different things on a computer, such as writing documents, browsing the internet, watching videos and playing games. Without software, the computer would not know what tasks to perform.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
= Hardware and software work together to make a computer work properly. Hardware is the physical part of the computer, while software gives it instructions. For example, when I type something on a keyboard, the computer receives the information and the software helps display the words on the screen. The CPU processes the instructions, and the monitor shows the results. Hardware and software depend on each other because both are needed for a computer to perform useful tasks.
