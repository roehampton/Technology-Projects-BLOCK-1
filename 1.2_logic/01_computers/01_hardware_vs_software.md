# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware is the physical part of a computer system that you can see and touch. It includes devices such as the keyboard, mouse, monitor, printer, hard drive, motherboard, and central processing unit (CPU). Hardware works together to perform tasks and process data. Without hardware, a computer would not be able to operate. Hardware also relies on software, which provides instructions for how the hardware should function. Together, hardware and software enable users to complete tasks such as writing documents, browsing the internet, playing games, and storing information.

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a collection of programs, instructions, and data that tells a computer how to perform specific tasks. Unlike hardware, software cannot be touched because it exists in digital form. Examples of software include operating systems such as Windows, web browsers like Google Chrome, word processing applications such as Microsoft Word, and mobile apps. Software enables users to interact with computer hardware and complete tasks efficiently. Without software, hardware would not know what actions to perform, making a computer unusable. Software and hardware work together to help users create documents, browse the internet, communicate, and perform many other everyday activities.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software interact by working together to make a computer function properly. Hardware refers to the physical components of a computer, such as the keyboard, mouse, monitor, and processor, while software consists of the programs and instructions that tell the hardware what to do. When a user performs an action, such as typing on a keyboard, the hardware sends information to the software. The software processes the information and instructs the hardware to display the results on the screen. Without software, hardware would not know how to operate, and without hardware, software could not run. Together, they enable computers to perform tasks efficiently and effectively.
