## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
### 1. Explain Hardware

Hardware is the physical parts of a computer that you can see and touch. Examples include the keyboard, mouse, monitor and CPU. Each part has a different job. For example, the keyboard is used to type, the mouse helps you click on things, and the monitor shows information on the screen. All these parts work together to help the computer function.

### 2. Explain Software

Software is the programs and apps that you use on a computer. You cannot touch software because it is not a physical object. Examples include Microsoft Word, Google Chrome and Windows. Software helps you do different tasks, such as writing documents, searching the internet and playing games. Without software, a computer would not know what to do.

### 3. How Do Hardware and Software Interact?

Hardware and software work together to make a computer work. Software gives the computer instructions, and the hardware follows them. For example, when I type something using a keyboard, the computer processes the information and displays the words on the monitor. The keyboard and monitor are hardware, while the program I use to type is software. Both are needed for a computer to work properly.
