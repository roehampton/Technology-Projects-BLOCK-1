# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
= Hardware is everything you can physically see and touch on a computer. It includes things like the keyboard, mouse, monitor, printer, and speakers. These parts help us use a computer to do different tasks, such as typing, playing games, watching videos, and saving files. Hardware is important because, without it, we wouldn't be able to use a computer properly. Unlike software, which includes apps and programs, hardware is made up of real, physical parts.




## Explain Software
Write **at least 50 words** explaining what software is.
= Software is a set of programs and instructions that tells a computer what to do. Unlike hardware, software cannot be physically touched because it is not a physical part of the computer. Examples of software include games, web browsers, Microsoft Word, and apps. Software helps us do different tasks, such as writing documents, browsing the internet, watching videos, and playing games. Without software, a computer would not be able to perform the tasks we need it to do.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
= Hardware and software work together to make a computer function. Hardware is the physical part of a computer, while software gives it instructions on what to do. For example, when you type on a keyboard, the hardware sends the information to the computer, and the software processes it and displays the words on the screen. Both are important because hardware needs software to work properly, and software needs hardware to run.
