# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
-ANSWER = Hardware refers to the physical parts of a computer that we can see and touch. For example, a keyboard, mouse, monitor, processor, motherboard, and hard drive are all types of hardware. Each part has a different job, but they work together to make the computer function properly. Without hardware, we would not be able to use a computer to perform everyday tasks.

## Explain Software
Write **at least 50 words** explaining what software is.
-ANSWER = Software is a set of programs and instructions that tells a computer what to do. Unlike hardware, software cannot be physically touched. Examples of software include Windows, Microsoft Word, Google Chrome, and Python. We use software to write documents, browse the internet, watch videos, and create programs. Without software, computer hardware would not know what tasks to perform.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
ANSWER = Hardware and software work together to make a computer useful. Software gives instructions, and hardware carries them out. For example, when I open a web browser and search for something, the software processes my request while the processor and memory help perform the task. The monitor then displays the results on the screen. Both hardware and software depend on each other to make a computer work properly.
