# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer or electronic device that we can see and touch. It includes all the components that help a computer work properly. Hardware works together with software, which consists of programs and instructions that tell the computer what to do.

Examples of computer hardware include the keyboard, mouse, monitor, CPU (Central Processing Unit), motherboard, RAM (Random Access Memory), hard drive, speakers, and printer.

Hardware can be divided into different types, such as input devices, output devices, processing devices, and storage devices. For example, a keyboard is used to enter information, a monitor displays results, the CPU processes data, and a hard drive stores files.

In conclusion, hardware is an essential part of a computer because, without it, software cannot run on a physical computer system.

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of programs, instructions, and data that tells a computer how to perform different tasks. Unlike hardware, software cannot be touched physically because it is made up of digital instructions. Software helps users perform activities such as typing documents, playing games, browsing the internet, and watching videos.

There are two main types of software: system software and application software. System software, such as operating systems, manages computer hardware and other programs. Application software, such as Microsoft Word, Google Chrome, and Paint, helps users complete specific tasks.

In conclusion, software is an essential part of a computer because it provides instructions that allow the hardware to work and perform useful tasks.


## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware is the physical part of a computer, while software is the set of programs and instructions that tell the hardware what to do.

When a user gives a command through software, the computer's hardware processes the instructions and produces the required result.

For example, when you type a document using Microsoft Word:

Keyboard (Hardware): You press keys to enter text.

Software: Microsoft Word receives and displays the text.

CPU (Hardware): The processor executes the instructions needed to run the program.

Monitor (Hardware): The text appears on the screen.

Storage (Hardware): The document is saved for future use.

In conclusion, hardware and software depend on each other. Hardware needs software to perform specific tasks, while software needs hardware to run. Together, they allow a computer to perform different operations efficiently.
