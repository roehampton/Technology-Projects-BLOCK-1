# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer or electronic device that you can see and touch. Examples of hardware include the keyboard, mouse, monitor, motherboard, processor (CPU), memory (RAM), hard drive, and printer. Each component has a specific job that helps the computer work properly. For example, the keyboard allows users to enter information, while the monitor displays images and text. Hardware needs software to perform many of its tasks and carry out instructions.
## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of programs, applications, and instructions that tell a computer or electronic device what to do. Unlike hardware, software cannot be physically touched. Examples of software include operating systems such as Windows and macOS, web browsers such as Google Chrome, and applications such as Microsoft Word. Software allows users to complete tasks, including writing documents, playing games, browsing the internet, and editing pictures. Without software, a computer would not know which tasks to perform or how to carry them out.
## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function correctly. Software provides instructions, while hardware carries out those instructions. For example, when you type a document using Microsoft Word, the keyboard sends your input to the computer, the software processes the information, and the monitor displays the words on the screen. The operating system helps different hardware components communicate with software applications. Both hardware and software depend on each other to perform tasks effectively. Without hardware, software would have no device to run on, and without software, hardware would have no instructions to follow.
