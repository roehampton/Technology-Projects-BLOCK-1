# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
A hardware is what includes all the physical parts of a computer , such as the central processing unit , random-access memory , motherboard , computer data storage , graphics card , sound card and computer case . It also includes external devices of the computer such as monitor , mouse , keyboards and speakers. Hardware is typically directed by the software to execute any command or instruction.
---

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of instructions and documentation that tells a computer what to do or how to perform a task. Software includes all different programs on a computer, such as applications and the operating system. Software it also refers to the intangible programs and instructions like Windows, MS Word, or Chrome that tell hardware what to do.
---
