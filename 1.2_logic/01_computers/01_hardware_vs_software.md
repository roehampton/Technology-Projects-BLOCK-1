# Part 1 – Hardware vs Software
Hardware refers to all the physical components of a computer that can be seen and touched. These components are responsible for receiving data, processing information, storing files, and displaying results. Hardware is manufactured using electronic and mechanical components.
[**examples**: CPU(central processing unit), keyboard, Mouse, Monitor.

Software refers to the programs, application, and instruction that tells a computer how to perform different tasks. Unlike hardware, software cannot be physically touched, although it can be seen running on a screen. software is created by programming using programming language.
**TYPES AND EXAMPLES OF SOFTWARE**
[system software:operating system, device drivers, utility programes.
[Application Software: Microsoft word, Microsoft Excel, Google Chrome, Power Point, Photo-editing application.
## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Computer hardware refers to the collection of physical, tangible components and electronic devices that forms a computer system and enable it to perform various operations, including data input, processing, storage, output, and communications. It consists of interconnected components such as the central processing unit(CPU), motherboard, Random Acess Memory  (RAM), Storage devices, input devices, output devices, and networking equipments.
**IN simple terms, Hardware is the physical foundation of a computer sysytem that carries out the operations necessary to process data and produce meaningful results under the control the software.**

## Explain Software
Write **at least 50 words** explaining what software is.
---Computer software refers to a collection of programs, instructions, procedures, and related data that direct a computer system to perform specific tasks and operations. Unlike hardware, software is intangible and cannot be physically touched. It is developed using programming languages and operates by instructing the computer's hardware on how to process data, store information, execute calculations, and produce meaningful results.
**In simple terms, software is the logical component of a computer system that provides instructions and controls hardware operations to perform tasks, solve problems, and meet users' requirements.**
