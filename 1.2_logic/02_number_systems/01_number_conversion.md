## Conversion from One Base to Another
1. **Convert the decimal number 156 to:**
   - Binary=10011100_2
   - Octal=234_8
   - Hexadecimal=9C_16

2. **Convert the binary number 101101 to:**
   - Decimal=45_10
   - Octal=55_8
   - Hexadecimal=2D_16

3. **Convert the octal number 745 to:**
   - Decimal=485_10
   - Binary=111100101_2
   - Hexadecimal=1E5_16

4. **Convert the hexadecimal number 3F9 to:**
   - Decimal=1017_10
   - Binary=1111111001_2
   - Octal=1771_8
