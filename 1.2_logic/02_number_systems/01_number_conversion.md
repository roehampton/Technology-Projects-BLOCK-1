## Conversion from One Base to Another
1. **Convert the decimal number 156 to:**
   - Binary= 10011100(2)
   - Octal=  234(8)
   - Hexadecimal= 9C(16)

2. **Convert the binary number 101101 to:**
   - Decimal= 45(10)
   - Octal=  55(8)
   - Hexadecimal= 2D(16)

3. **Convert the octal number 745 to:**
   - Decimal=  485(10)
   - Binary=  111100101(2)
   - Hexadecimal= 1E5(16)

4. **Convert the hexadecimal number 3F9 to:**
   - Decimal= 1017(10)
   - Binary= 1111111001(2)
   - Octal= 1771(8)
