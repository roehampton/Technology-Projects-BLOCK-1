
## Fixed Point Representation
**Represent the decimal number in fixed-point binary:**
   - 12.75 with 4 bits for the integer part and 4 bits for the fractional part = 1100.1100_2$
   - 5.125 with 3 bits for the integer part and 5 bits for the fractional part = 101.00100_2$
   - 7.5 with 4 bits for the integer part and 4 bits for the fractional part = 0111.1000_2$
