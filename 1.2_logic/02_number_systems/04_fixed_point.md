
## Fixed Point Representation
**Represent the decimal number in fixed-point binary:**        123
   - 12.75 with 4 bits for the integer part and 4 bits for the fractional part
     = integer parts: 12 = 1100
     = Fractional parts 0.75 = .1100
     so that the answer is 1100.1100

     
   - 5.125 with 3 bits for the integer part and 5 bits for the fractional part
     = integer parts: 5 = 101
     = Fractional parts:0.125 = .00100
     so that the answer is 101.00100

     
   - 7.5 with 4 bits for the integer part and 4 bits for the fractional part
     = integer parts: 7=0111
     =fractionql part=0.5=.1000
     so that the answer is 0111.1000
